# Checklist Cepat - Translate Semua Section

## A. Identitas
- [ ] Label: Name, Age, Date of birth, Address, MR, Date of Admission, DPJP
- [ ] Kosong jika tidak ada info
- [ ] Name: Mr./Mrs. + huruf depan
- [ ] Referral hanya bila ada rujukan

## B. Anamnesis
- [ ] Chief complaint bold
- [ ] Chest pain triple criteria
- [ ] Onset + durasi + NRS
- [ ] Diaphoresis/Nausea/Vomiting (+)/(-)
- [ ] SOB/DOE/PND/Orthopnea (+)/(-)
- [ ] Previous chest pain, Palpitations (+)/(-)
- [ ] Other complaints (+)/(-)
- [ ] Riwayat PCI (tahun, pembuluh, stent)
- [ ] Obat rutin
- [ ] Coronary Risk Factors bold
- [ ] HT/DM/Merokok/PJ Keluarga

## C. Physical Examination
- [ ] Compos mentis baris 1
- [ ] TTV 1 baris (titik)
- [ ] Mata (+)/(-)
- [ ] JVP, Heart sounds, Lungs, Abdomen, Extremities
- [ ] Semua (+)/(-)

## D. Assessment
- [ ] Tanpa header & bullet di codeblock
- [ ] 1 baris per diagnosis
- [ ] Istilah baku (STEMI, CAD, HFmrEF)
- [ ] Score angka tetap

## E. Therapy
- [ ] Tanpa header & bullet di codeblock
- [ ] 1 baris per obat
- [ ] IVFD baris pertama
- [ ] Format dosis/frekuensi/rute

## F. Plan
- [ ] Tanpa header & bullet di codeblock
- [ ] 1 baris per plan
- [ ] Istilah teknis tetap

## G. Bahasa
- [ ] (+) / (-)
- [ ] Bukan denies/present/absent
- [ ] Broken English OK
- [ ] No fiksi/halusinasi
